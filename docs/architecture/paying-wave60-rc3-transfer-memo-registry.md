= Paying Wave 60 RC-3 Transfer Memo Registry

This wave adds a compact transfer memo report for continuing Paying work in a new chat or downstream workflow.

== Command

[source,bash]
----
composer report:rc3-transfer-memo
----

== Purpose

The report summarizes:

* component;
* namespace;
* milestone;
* essential verification commands;
* next recommended phase;
* required RC-3 proof scripts.

== Non-scope

* No production code change.
* No test execution.
* No PHPUnit configuration change.
