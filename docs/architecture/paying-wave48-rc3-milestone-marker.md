= Paying Wave 48 RC-3 Milestone Marker

Adds `composer report:rc3-milestone`.

The marker verifies that the RC-3 runtime proof surface is assembled:

* canonical readiness;
* runtime issue inventory;
* runtime proof closure;
* runtime proof core;
* Composer hygiene;
* unit, functional, and security scripts;
* package description;
* `App\Paying\` PSR-4.

No production code change. No test execution. No PHPUnit configuration weakening.
