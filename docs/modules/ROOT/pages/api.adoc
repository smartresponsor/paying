== OpenAPI contract surface

NelmioApiDocBundle remains the canonical HTTP contract generator for this repository. Swagger UI is the browser-facing viewer for that contract and must stay only a presentation layer.

The machine-readable HTTP contract stays outside Antora narrative pages and remains the canonical generated artifact:

* `docs/api/openapi.yaml`

Runtime publication points are expected at:

* `/api/docs`
* `/api/docs.json`

If Nelmio/OpenAPI is present, the contract should continue to be generated and served there rather than duplicated manually inside Antora.
